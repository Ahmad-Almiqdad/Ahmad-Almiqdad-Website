# Ahmad Al-Miqdad · Portfolio

Open [`index.html`](index.html) in a browser to preview Pencil to Paint. The pencil drawings reveal the artwork once on page load. Each print opens the artwork viewer.

## Publish on GitHub Pages

The site uses HTML, CSS, and browser JavaScript and requires no build or installation.

1. Push the site files, `assets/`, and `.nojekyll` to the branch you want to publish.
2. In the repository, go to **Settings → Pages**.
3. Select **Deploy from a branch**, choose **main** and **/ (root)**, then save.

[GitHub Pages publishing instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
